> **能力标识:** `yiji-recommendation`  
> **优先级:** P0  
> **Phase:** Phase 1（干支计算+宜忌推荐随 MVP 交付）  
> **依赖:** `design-tokens`, `habit-tracking`（宜事项与用户习惯匹配）  
> **状态:** 草稿
> **根设计:** [design.md](../design.md)（Commands/目录/代码风格/测试/边界）

---

## 1. 概述

基于中国传统八卦五行理论，根据公历日期计算天干地支，查表推荐当日宜忌事项。算法完全本地执行，无需网络请求。

> **Phase 归属说明：** 干支计算（庚申日·金旺）和宜忌推荐卡片均为 MVP 首页的一部分，随 Phase 1 交付。天干地支数据和宜忌表随小程序打包。

### 1.1 空状态

- **新用户无习惯匹配时**：宜事项照常展示（不依赖用户习惯），但去掉 📖 跳转图标
- **忌事项**：始终展示，不依赖用户数据

---

## 2. 算法流程

```
输入: 公历日期 (年/月/日)
        │
        ▼
┌───────────────────┐
│  1. 计算年柱      │ ← 年份 → 天干地支查表
├───────────────────┤
│  2. 计算月柱      │ ← 年份 + 月份 → 天干地支查表
├───────────────────┤
│  3. 计算日柱      │ ← 年 + 月 + 日 → 天干地支查表
├───────────────────┤
│  4. 确定五行属性   │ ← 日干 → 五行映射
├───────────────────┤
│  5. 查询宜忌列表   │ ← 五行 → 宜/忌事项
└───────────────────┘
        │
        ▼
输出: "庚申日 · 金旺 · 宜读书静坐复盘 · 忌冲动决策"
```

## 3. 天干地支计算

### 3.1 基本概念

| 概念 | 说明 | 元素 |
|------|------|------|
| 十天干 | 甲、乙、丙、丁、戊、己、庚、辛、壬、癸 |
| 十二地支 | 子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥 |
| 十二生肖 | 鼠、牛、虎、兔、龙、蛇、马、羊、猴、鸡、狗、猪 |

### 3.2 年柱计算

基于公历年份查表。约公元前 2697 年为干支纪年起始（甲子年）。

```
公式: 年干 = (year - 4) % 10
      年支 = (year - 4) % 12

示例: 2025年
      年干 = (2025 - 4) % 10 = 2021 % 10 = 1 → 乙
      年支 = (2025 - 4) % 12 = 2021 % 12 = 5 → 巳
      输出: 乙巳年
```

### 3.3 月柱计算

月柱以节气为界，非公历月份。

```
简化查表法（不考虑精确节气，按公历月份近似）:

月份   地支    天干（根据年干推算）
1月    寅      丙/甲/壬/庚/戊
2月    卯      丁/乙/癸/辛/己
...（完整查表见附录）
```

> **实现建议**：使用预定义查表数组，不涉及实时计算。

### 3.4 月柱完整查表

月柱由「月支 + 年干」共同决定。月支以节气为界，以下近似表按公历月份对应：

| 公历月份 | 月支 | 甲/己年 | 乙/庚年 | 丙/辛年 | 丁/壬年 | 戊/癸年 |
|---------|------|---------|---------|---------|---------|---------|
| 1月 | 寅 | 丙寅 | 戊寅 | 庚寅 | 壬寅 | 甲寅 |
| 2月 | 卯 | 丁卯 | 己卯 | 辛卯 | 癸卯 | 乙卯 |
| 3月 | 辰 | 戊辰 | 庚辰 | 壬辰 | 甲辰 | 丙辰 |
| 4月 | 巳 | 己巳 | 辛巳 | 癸巳 | 乙巳 | 丁巳 |
| 5月 | 午 | 庚午 | 壬午 | 甲午 | 丙午 | 戊午 |
| 6月 | 未 | 辛未 | 癸未 | 乙未 | 丁未 | 己未 |
| 7月 | 申 | 壬申 | 甲申 | 丙申 | 戊申 | 庚申 |
| 8月 | 酉 | 癸酉 | 乙酉 | 丁酉 | 己酉 | 辛酉 |
| 9月 | 戌 | 甲戌 | 丙戌 | 戊戌 | 庚戌 | 壬戌 |
| 10月 | 亥 | 乙亥 | 丁亥 | 己亥 | 辛亥 | 癸亥 |
| 11月 | 子 | 丙子 | 戊子 | 庚子 | 壬子 | 甲子 |
| 12月 | 丑 | 丁丑 | 己丑 | 辛丑 | 癸丑 | 乙丑 |

> **使用方式：** 先根据年干确定行（年干=甲/己 查第2列，依此类推），再根据公历月份找到对应的月柱。

### 3.5 日柱计算

日柱计算较为复杂，建议使用**预置查表法**：

1. 预计算未来 5-10 年的每日干支数据（约 1825-3650 条）
2. 以 JSON 对象形式存储：`{ '2025-10-15': { gan: 7, zhi: 9 } }`
3. 按日期直接查找

> **离线可用**：数据随小程序打包，约 50-100KB。

## 4. 五行映射

### 4.1 天干 → 五行

| 天干 | 五行属性 |
|------|----------|
| 甲、乙 | 木 |
| 丙、丁 | 火 |
| 戊、己 | 土 |
| 庚、辛 | 金 |
| 壬、癸 | 水 |

### 4.2 五行强弱判定

以日干（日柱的天干）为主，以月支（月柱的地支）为辅：

| 规则 | 输出 |
|------|------|
| 日干属性 | 如「庚」→ 金旺 |
| 月支辅助 | 如生于「申」月 → 金更旺 |

> **简化实现**：直接输出日干对应的五行属性，不深入考虑月令旺衰。

## 5. 宜忌推荐规则

### 5.1 五行 → 宜忌表

| 五行 | 宜 | 忌 | 关联习惯 |
|------|----|----|---------|
| 金旺 | 读书、静坐、复盘 | 冲动决策 | 阅读、冥想、日记 |
| 木旺 | 运动、写作、规划 | 过度劳累 | 跑步、写作、计划 |
| 水旺 | 社交、学习、创作 | 熬夜 | 社交、学习、创作 |
| 火旺 | 执行、整理、沟通 | 急躁行事 | 行动、整理、沟通 |
| 土旺 | 反思、修养、规划 | 拖延 | 冥想、日记、规划 |

### 5.2 推荐算法

1. 根据日干确定当日五行
2. 从五行 → 宜忌表获取宜事项和忌事项
3. 将宜事项与用户已创建的习惯交叉匹配
4. 匹配到的习惯显示 📖 图标，可直接点击跳转

### 5.3 输出格式

```
宜 读书📖 静坐🧘 复盘✍️
忌 冲动决策⚡
```

- 宜事项：最多展示 3 项（优先展示与用户习惯匹配的）
- 忌事项：最多展示 2 项
- 图标：每个事项后跟对应 emoji

## 6. 加载与错误状态

### 6.1 加载中

- 数据为本地预置 JSON + 常量，**理论上无加载延迟**
- 若首次打开时本地数据尚未就绪：显示骨架占位，文案「正在推算今日宜忌…」

### 6.2 数据加载失败

- 本地 JSON 文件损坏或缺失：显示「宜忌数据未加载」，提供重新初始化按钮
- 恢复方式：从云存储下载一份备份数据覆盖本地

### 6.3 无法匹配习惯

- 用户无习惯或所有习惯不匹配宜事项：宜事项照常展示 3 项推荐，去掉 📖 图标
- 不因无匹配习惯而显示空内容

## 8. 验收标准

| # | 验收项 | 预期结果 |
|---|--------|---------|
| 1 | 农历日期与干支显示正确 | 与已知日期对应（如 2025-10-15 → 庚申日） |
| 2 | 五行属性判断正确 | 庚申日 → 金旺 |
| 3 | 宜事项每日变化 | 不同日期推荐不同 |
| 4 | 宜事项匹配用户习惯 | 如用户有「阅读」习惯则显示「读书📖」 |
| 5 | 完全离线可用 | 无网络时仍正常显示 |
| 6 | 日期跨年正确 | 2025 年 12 月 31 日 → 2026 年 1 月 1 日过渡正确 |
