# Task Management — 任务管理

> **能力标识:** `task-management`  
> **优先级:** P0  
> **Phase:** Phase 1（MVP）  
> **依赖:** `design-tokens`  
> **经验值接口:** 参见 `koi-growth-system` 第 3 节（完成任务后调用 `addExp(10)`）  
> **状态:** 草稿
> **根设计:** [design.md](../design.md)（Commands/目录/代码风格/测试/边界）

---

## 1. 概述

任务管理是应用的核心能力之一。用户可创建、编辑、完成任务，任务按分类（生活/工作/学习/健康）和优先级（重要/普通/不急）组织。完成任务可获得锦鲤经验值。

---

## 2. 数据模型

```javascript
{
  id: String,              // 唯一标识（自动生成）
  userId: String,          // 微信 openid
  title: String,           // 任务标题（必填，最长 50 字）
  note: String,            // 备注/描述（选填，最长 200 字）
  priority: 'high' | 'mid' | 'low',    // 优先级
  category: '生活' | '工作' | '学习' | '健康',  // 分类
  type: 'task',            // 固定为 'task'
  completed: Boolean,      // 完成状态
  completedAt: Date | null, // 完成时间
  createdAt: Date,         // 创建时间
  updatedAt: Date          // 更新时间
}
```

## 3. 功能列表

| 功能 | 描述 | 入口 |
|------|------|------|
| 创建任务 | 填写标题、备注、优先级、分类 | 首页浮动按钮 → 抽屉表单 |
| 完成任务 | 点击卡片切换完成态 | 首页混合列表 / 清单页 |
| 取消完成 | 再次点击已完成任务 | 任一列表页 |
| 查看任务 | 按分类分组查看 | 清单·打卡页「全部清单」Tab |
| 编辑任务 | 修改标题/备注/优先级/分类 | 长按任务卡片 → 编辑弹窗 |
| 删除任务 | 删除任务 | 长按任务卡片 → 删除确认 |
| 排序 | 按优先级/创建时间排序 | 清单页 |

## 4. 任务创建

### 4.1 表单字段

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| 计划名称 | 文本输入 | 是 | — | 最长 50 字 |
| 备注 | 多行文本 | 否 | 空 | 最长 200 字 |
| 优先级 | 选择器 | 是 | `mid`（普通） | 重要 / 普通 / 不急 |
| 分类 | 选择器 | 是 | `生活` | 生活 / 工作 / 学习 / 健康 |

### 4.2 创建后的行为

1. 任务写入云数据库
2. 首页混合列表实时更新
3. 概览卡片数字同步
4. Toast 提示「任务已创建」（参见 [design-tokens](./design-tokens.md) 第 6.4 节）

---

## 5. 任务完成/取消

### 5.1 完成任务

1. 用户点击任务卡片
2. 执行完成动画（参见 [design-tokens](./design-tokens.md) 第 6.2 节）
3. `completed: true`, `completedAt: now`
4. 锦鲤经验值 +10（参见 [koi-growth-system](./koi-growth-system.md) 第 3 节）
5. 卡片置灰（`opacity: 0.6`），标题加朱砂色删除线
6. 概览卡片「待完成」数字 -1

### 5.2 取消完成

1. 用户再次点击已完成任务
2. 印章动画反向消失
3. `completed: false`, `completedAt: null`
4. 卡片恢复不透明度，删除线消失
5. 概览卡片「待完成」数字 +1
6. **不扣除**已获得的锦鲤经验值

## 7. 任务编辑/删除

### 7.1 触发方式

长按任务卡片（≥500ms）→ 弹出操作菜单

### 7.2 操作菜单

| 操作 | 行为 |
|------|------|
| 编辑 | 弹出编辑弹窗（类似创建表单，预填当前值） |
| 删除 | 确认弹窗「确定删除此任务？」→ 确认后删除 |

### 7.3 删除逻辑

- 从数据库永久删除
- 概览卡片数字同步
- 如已获得锦鲤经验值，**不扣除**

---

## 8. 排序规则

| 排序方式 | 规则 |
|----------|------|
| 默认 | 未完成的按优先级(高→中→低) → 已完成排在末尾 |
| 按创建时间 | 最新的优先（全部任务混排） |
| 按分类 | 按分类分组，组内按优先级 |

排序切换控件位于清单页右上角。

---

## 9. 空状态与加载态

### 9.1 首次使用（无任务）

- 清单页「全部清单」Tab 显示：`还没有任务，去首页创建一个吧 📝`
- 空状态插画：极简线条风格（与设计规范一致）
- 隐藏排序切换控件（无数据可排序）

### 9.2 任务列表加载中

- 显示 3 行骨架屏（灰色圆角矩形脉冲）
- 每个骨架屏模拟任务卡片结构：标题条 + 备注条

### 9.3 任务加载失败

- 保留上次成功加载的数据（如有）
- 首次加载失败：错误提示 + 重试按钮
- Toast：「加载失败，请检查网络」

### 9.4 任务创建/编辑/删除失败

| 操作 | 失败处理 |
|------|----------|
| 创建 | Toast「创建失败，请重试」 |
| 编辑 | Toast「保存失败，请重试」 |
| 删除 | Toast「删除失败，请重试」 |

## 10. 验收标准

| # | 验收项 | 预期结果 |
|---|--------|---------|
| 1 | 创建任务成功 | 数据写入 DB，列表实时更新 |
| 2 | 标题为必填 | 空标题提交被阻止 |
| 3 | 完成任务动画正常 | 印章回弹自然，卡片置灰 |
| 4 | 取消完成恢复状态 | 卡片恢复原样，经验值不扣除 |
| 5 | 按分类分组展示 | 分类标题正确，组内排序正确 |
| 6 | 长按出现操作菜单 | 500ms 后弹出 |
| 7 | 编辑保存成功 | 修改字段更新到 DB 和 UI |
| 8 | 删除成功 | 数据从 DB 移除，UI 同步消失 |
| 9 | 任务完成 +10 经验值 | 锦鲤经验条增长 |
