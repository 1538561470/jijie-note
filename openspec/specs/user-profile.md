# User Profile — 用户资料与设置

> **能力标识:** `user-profile`  
> **优先级:** P1  
> **Phase:** Phase 6  
> **依赖:** `design-tokens`, `koi-growth-system`  
> **状态:** 草稿
> **根设计:** [design.md](../design.md)（Commands/目录/代码风格/测试/边界）

---

## 1. 概述

「我的」页面是用户个人中心，展示锦鲤成长系统、用户资料和设置菜单。相比首页和清单页，此页面功能密度较低，优先级为 P1（MVP 后可交付）。

## 3. 锦鲤展示区

### 3.1 构成元素

| 元素 | 内容 |
|------|------|
| 锦鲤动画 | SVG 动画锦鲤（参见 [koi-growth-system](./koi-growth-system.md) 第 4 节） |
| 用户名 | 微信昵称，18px Weight 600 |
| 等级 | `Lv.7` 标签，`--indigo-deep` 色 |
| 经验条 | 当前等级进度条 + 百分比 |
| 段位称号 | 如「鱼跃龙门」（参见 [koi-growth-system](./koi-growth-system.md) 第 2.2 节） |
| 进度提示 | 如「尚需 32 次打卡升级」 |

### 3.2 进度提示文案

| 条件 | 提示文案 |
|------|----------|
| 可升级 | 再完成 X 个任务即可升级 🎉 |
| 接近升级 | 差一点点！再完成 X 个任务 |
| 需习惯链 | 还需 X 条 ≥21 天习惯链 |
| 已满级 Lv.10 | 鱼跃龙门·已达化龙之境 🐉 |

## 4. 设置菜单

### 4.1 菜单列表

使用列表式布局，每行一个菜单项，右侧 `›` 箭头。

### 4.2 菜单项说明

| 菜单 | 功能 | 说明 |
|------|------|------|
| 锦鲤图鉴 | 跳转图鉴页 | 参见 [koi-growth-system](./koi-growth-system.md) 第 5 节 |
| 等级奖励 | 展示各等级解锁奖励 | 可领取的奖励列表 |
| 计划标签管理 | 编辑/添加分类标签 | 默认：生活/工作/学习/健康，可自定义 |
| 主题与外观 | 切换主题 | 可选：素简（默认）、墨色、朱砂（预留） |
| 农历日历设置 | 是否显示农历 | 开关切换 |
| 数据导出 | 导出任务/习惯数据 | JSON 或 CSV 格式 |
| 关于素简 | 版本信息、致谢 | 版本号、开源致谢 |

### 4.3 计划标签管理

| 功能 | 说明 |
|------|------|
| 查看标签 | 列表展示所有标签 |
| 添加标签 | 输入标签名称（最长 6 字） |
| 编辑标签 | 修改标签名称 |
| 删除标签 | 删除后已有任务/习惯的分类保持不变 |
| 默认标签 | 生活 / 工作 / 学习 / 健康（不可删除） |

### 4.4 主题与外观

| 主题 | 说明 | 实现方式 |
|------|------|----------|
| 素简（默认） | 宣纸白为主色调 | 默认 CSS 变量 |
| 墨色（预留） | 深色模式 | CSS 变量覆盖 |
| 朱砂（预留） | 朱砂红为主色调 | CSS 变量覆盖 |

> 主题通过切换 `data-theme` 属性实现 CSS 变量覆盖，无需换页。

### 4.5 数据导出

| 维度 | 规格 |
|------|------|
| 导出格式 | JSON / CSV |
| 数据范围 | 所有任务 + 习惯 + 打卡记录 |
| 导出方式 | 生成文件 → 通过微信转发/保存 |
| 隐私说明 | 数据仅包含用户自己的内容 |

## 5. 用户资料

### 5.1 数据模型

```javascript
{
  openid: String,           // 微信 openid（只读）
  nickname: String,         // 微信昵称
  avatarUrl: String,        // 微信头像 URL
  signature: String,        // 个性签名（选填，最长 30 字）
  createdAt: Date,          // 注册时间
  settings: {
    theme: 'default' | 'ink' | 'cinnabar',
    lunarEnabled: Boolean,  // 是否显示农历
    showKoi: Boolean,       // 是否显示锦鲤
  }
}
```

### 5.2 用户资料卡片

位于锦鲤展示区上方或整合显示：

| 元素 | 来源 |
|------|------|
| 头像 | 微信头像（圆形裁切） |
| 昵称 | 微信昵称 |
| 签名 | 用户自定义，最长 30 字（预留，P1 可不实现） |

## 6. 空状态与加载态

### 6.1 新用户首次进入

- 锦鲤展示区：显示 Lv.0 鱼卵（默认形态），经验条为 `0%`
- 段位称号：`潜龙勿用`
- 进度提示：`完成第一个任务来唤醒你的锦鲤 🥚`
- 锦鲤图鉴菜单项：可点击进入（全部未解锁）
- 设置菜单：各项均可正常进入

### 6.2 用户数据加载中

- 锦鲤区域显示灰色占位（鱼形轮廓脉冲动画）
- 用户名显示 `—`
- 经验条显示 0%
- 菜单项可点击（数据为本地默认值）

### 6.3 用户数据加载失败

- 保留上次数据（如有）
- 新用户首次失败：显示重试页
- 设置项使用默认值（不影响使用）

## 7. 页面交互

| 交互 | 行为 |
|------|------|
| 点击锦鲤 | 触发交互动画（靠近/跃水，取决于等级） |
| 点击锦鲤图鉴 | 跳转图鉴页 |
| 点击菜单项 | 跳转子页面或弹出功能 |
| 下拉刷新 | 重新加载锦鲤数据 |

## 7. 验收标准

| # | 验收项 | 预期结果 |
|---|--------|---------|
| 1 | 锦鲤展示区数据正确 | 等级/经验/称号与实际一致 |
| 2 | 经验条进度百分比准确 | 与 `exp / requiredExp` 一致 |
| 3 | 进度提示文案合理 | 根据升级条件动态变化 |
| 4 | 设置菜单点击跳转 | 各菜单项打开对应功能 |
| 5 | 标签管理 CRUD | 标签增删改查正常 |
| 6 | 主题切换生效 | CSS 变量覆盖，页面色调改变 |
| 7 | 数据导出成功 | 生成的文件可正常打开 |
| 8 | 关于页面显示版本号 | 与项目版本一致 |
