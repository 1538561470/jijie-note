> **能力标识:** `habit-tracking`  
> **优先级:** P0  
> **Phase:** Phase 1（MVP）  
> **依赖:** `design-tokens`, `koi-growth-system`, `lunar-calendar`  
> **状态:** 草稿
> **根设计:** [design.md](../design.md)（Commands/目录/代码风格/测试/边界）

---

## 1. 概述

微习惯打卡系统让用户创建和追踪日常习惯。习惯与任务在首页混合展示，但具有独立的打卡逻辑、连续天数计算和中文称号体系。

---

## 2. 数据模型

### 2.1 习惯定义

```javascript
{
  id: String,              // 唯一标识
  userId: String,          // 微信 openid
  name: String,            // 习惯名称（如「喝水」「晨跑」）
  target: Number,          // 每日目标次数（如 8 杯）
  unit: String,            // 单位（如「杯」「分钟」「页」）
  frequency: {             // 频率设置
    type: 'daily' | 'weekday' | 'custom',
    days: [1,2,3,4,5]     // 当 type='custom' 时，1=周一 7=周日
  },
  category: '生活' | '工作' | '学习' | '健康',  // 分类
  createdAt: Date,
  updatedAt: Date
}
```

### 2.2 打卡记录

```javascript
{
  id: String,
  habitId: String,         // 关联习惯 ID
  userId: String,
  date: String,            // 'YYYY-MM-DD' 格式
  count: Number,           // 当日打卡次数
  createdAt: Date
}
```

## 3. 打卡逻辑

### 3.1 基础规则

| 规则 | 说明 |
|------|------|
| 每日多次打卡 | 同一习惯可在当日多次打卡（如喝水 8 杯分多次记录） |
| 当日完成判定 | `count >= target` 即视为当日完成 |
| 打卡上限 | 单日单习惯 `count <= target * 2`（避免误操作） |

### 3.2 打卡交互

1. 用户点击习惯卡片
2. `count += 1`（若当日无记录则创建新记录）
3. 判断是否达到 `target`：
   - 未达到：继续计数
   - 已达到：标记为当日完成，复选框变为已勾选
   - 超额：计数器显示「+n」
4. 锦鲤经验值 +5（参见 [koi-growth-system](./koi-growth-system.md) 第 3 节）
5. 月度日历对应日期盖朱砂印
6. 连续天数重新计算

### 3.3 取消打卡

- 点击已完成的习惯卡片 → 弹出确认「取消今日打卡？」
- 确认后 `count -= 1`，如 `count < target` 则取消完成状态
- **不扣除**已获得的锦鲤经验值

## 4. 连续天数与中文称号

### 4.1 计算规则

连续天数：**从最近一次未完成日开始向前计算**。

```
示例：假设今日是 10 月 15 日
打卡记录：... 10/12 ✓  10/13 ✓  10/14 ✗  10/15 ✓
                             ↑
                        未打卡日 → 连续天数重置为 1
```

| 规则 | 说明 |
|------|------|
| 起始点 | 从今日（或最近打卡日）开始向前追溯 |
| 断点 | 遇到未打卡日即停止 |
| 频率感知 | 习惯只在设定的频率日才检查（如「工作日」周末不中断连续） |

### 4.2 中文称号体系

| 连续天数 | 称号 | 解锁条件 |
|----------|------|----------|
| 7 天 | 一周有成 | 首次连续 7 天打卡 |
| 21 天 | 三周之功 | 首次连续 21 天打卡 |
| 30 天 | 一月之期 | 首次连续 30 天打卡 |
| 100 天 | 百日筑基 | 首次连续 100 天打卡 |
| 365 天 | 周而复始 | 连续打卡一整年 |

### 4.3 称号奖励

| 解锁 | 锦鲤经验值奖励 |
|------|---------------|
| 连续 7 天 | +50 exp（一次性） |
| 连续 21 天 | +200 exp（一次性） |
| 连续 100 天 | +1000 exp（一次性，仅一次） |

> 每个习惯独立计算连续天数，奖励也独立发放。

### 4.4 展示位置

- **首页习惯卡片**：`🔥 连续7天 · 一周有成`
- **清单·打卡页底部**：`🔥 最长连续：7天「一周有成」`

## 5. 习惯管理

### 5.1 创建习惯

通过首页浮动按钮 → 选择「习惯」类型 → 填写表单（参见 [home-dashboard](./home-dashboard.md) 第 7 节）

### 5.2 编辑习惯

| 字段 | 可编辑 | 说明 |
|------|--------|------|
| 名称 | ✅ | — |
| 每日目标次数 | ✅ | 修改后不影响已有打卡记录 |
| 单位 | ✅ | — |
| 频率 | ✅ | 修改后连续天数重新计算 |
| 分类 | ✅ | — |

### 5.3 删除习惯

- 删除习惯将同时删除其所有打卡记录
- 已获得的锦鲤经验值**不扣除**
- 确认弹窗：「删除此习惯将同时删除所有打卡记录，确定？」

## 6. 与任务的区别

| 维度 | 任务 | 习惯 |
|------|------|------|
| 模型字段 | `type: 'task'` | `type: 'habit'` + `habitConfig` |
| 完成方式 | 单次完成 | 每日可达标多次 |
| 前置图标 | `○` 圆形 | `☑` 复选框 |
| 连续天数 | 无 | 有，🔥 显示 |
| 经验值 | 完成 +10 exp | 每次打卡 +5 exp |
| 完成态 | 永久完成 | 每日重置 |

## 7. 空状态与加载态

### 7.1 首次使用（无习惯）

- 清单页「本月打卡」Tab：月历正常显示（空月份），底部显示 `🔥 还没有习惯，先去创建一个吧`
- 首页不显示习惯卡片（只显示任务卡片）
- 习惯管理列表：`还没有习惯 📋`

### 7.2 打卡数据加载中

- 月历区域显示骨架屏（灰色方格）替代日期格
- 习惯列表显示 2 个骨架卡片
- 连续天数显示 `—天`

### 7.3 打卡提交失败

- 点击打卡后如果网络失败：回滚勾选框状态，Toast「打卡失败，请重试」
- 连续天数保持打卡前的值不变
- 经验值不增加
