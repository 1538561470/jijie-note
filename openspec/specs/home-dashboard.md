# Home Dashboard — 首页

> **能力标识:** `home-dashboard`  
> **优先级:** P0  
> **Phase:** Phase 1（MVP）  
> **依赖:** `design-tokens`, `lunar-calendar`, `yiji-recommendation`, `task-management`, `habit-tracking`  
> **状态:** 草稿
> **根设计:** [design.md](../design.md)（Commands/目录/代码风格/测试/边界）

首页是用户打开小程序后的第一屏，聚合展示今日信息、任务概览和计划列表。用户在此完成绝大多数日常操作：查看宜忌、了解进度、完成任务/打卡、添加新计划。

### 2.1 页面区域划分

| 区域 | 内容 | 数据来源 |
|------|------|----------|
| 问候区 | 根据时段显示「早上好/下午好/晚上好」 | 本地时间 |
| 日期区 | 公历 + 农历 + 干支 + 五行 | `lunar-calendar` + `yiji-recommendation` |
| 宜忌卡片 | 今日宜/忌推荐 | `yiji-recommendation` |
| 概览卡片 | 全部任务 / 待完成 / 今日习惯 | `task-management` + `habit-tracking` |
| 今日计划 | 任务·习惯混合列表 | `task-management` + `habit-tracking` |
| 浮动按钮 | 添加计划/习惯 | 底部抽屉表单 |

## 4. 宜忌卡片

参见 [yiji-recommendation spec](./yiji-recommendation.md) 第 2 节。

### 4.1 交互

- 点击「宜」项目直接跳转对应习惯的打卡页
- 卡片整体不可滚动，固定展示

---

## 5. 概览卡片

三张统计卡片水平排列，等宽。

| 卡片 | 数据 | 视觉要点 |
|------|------|----------|
| 全部任务 | 总任务数（含已完成） | 数字为主色 `--indigo-deep` |
| 待完成 | 未完成任务数 | 数字用 `--cinnabar`，带朱砂红圆点装饰 |
| 今日习惯 | 已打卡数/总习惯数（如 `3/5`） | 分数形式，背景用 `--card-bg` |

### 5.1 交互

- 点击「全部任务」→ 跳转清单·打卡页「全部清单」Tab
- 点击「待完成」→ 跳转清单·打卡页，焦点到第一个未完成任务
- 点击「今日习惯」→ 跳转清单·打卡页「本月打卡」Tab

## 6. 今日计划（任务·习惯混合列表）

任务和习惯在同一个信息流中平级展示。

### 6.1 前置图标区分

| 类型 | 图标 | 样式 |
|------|------|------|
| 任务 | `○` 圆形勾选框 | 空心圆，未完成时 `--ink-tertiary` |
| 习惯 | `☑` 复选框 | 方形复选框 + 连续天数 `🔥` 标签 |

### 6.2 任务卡片结构

```
○ 任务标题                    分类标签
   ● 优先级 · 备注/描述
```

- 优先级标记：高优先 `●` 朱砂红 / 中优先 `●` 黛蓝 / 低优先 `●` 灰色
- 分类标签：圆角小标签（参见 [design-tokens](./design-tokens.md) 第 4 节）
- 备注文字使用 `--ink-secondary`

### 6.3 习惯卡片结构

```
☑ 习惯名称                    分类标签
   🔥 连续7天    已打卡 ✓
```

- 连续天数：使用中文称号（参见 [habit-tracking](./habit-tracking.md) 第 4 节）
- 今日已打卡：右侧显示 `✓` 标记

### 6.4 任务完成交互

1. 点击任务卡片任意位置
2. 卡片微缩（`scale: 0.985`），持续 100ms
3. 勾选框由空心圆变为朱砂红实心 + 白色勾
4. 右侧「完」字印章弹出动画（参见 [design-tokens](./design-tokens.md) 第 6.2 节）
5. 卡片整体透明度降至 `0.6`
6. 标题显示朱砂色删除线

### 6.5 习惯打卡交互

1. 点击习惯卡片任意位置
2. 复选框变为已勾选状态
3. 当日打卡记录写入数据库
4. 月度日历对应日期盖朱砂印
5. 连续天数重新计算并更新

## 7. 添加计划/习惯（底部抽屉）

### 7.1 触发方式

点击右下角浮动 `➕` 按钮 → 底部抽屉滑入

### 7.2 表单字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 计划名称 | 文本输入 | 是 | 最长 50 字 |
| 备注 | 文本输入（多行） | 否 | 最长 200 字 |
| 优先级 | 选择器 | 是 | 重要 / 普通 / 不急 |
| 分类 | 选择器 | 是 | 生活 / 工作 / 学习 / 健康 |
| 类型 | 切换 | 是 | 任务 / 习惯 |

### 7.3 习惯频率设置

当类型选择「习惯」时，额外展示频率设置：

| 频率选项 | 说明 |
|----------|------|
| 每天 | 每日都需要打卡 |
| 工作日 | 周一至周五需要打卡 |
| 自定义 | 勾选具体星期几（多选） |

### 7.4 交互规范

- 底部滑入抽屉：0.4s `cubic-bezier(0.34, 1.56, 0.64, 1)` 弹性缓出（参见 [design-tokens](./design-tokens.md) 第 6.1 节）
- 遮罩层半透明，点击遮罩关闭抽屉
- 表单项使用 `--input-bg` 色块区分区域，不使用分割线
- 提交成功后弹出 Toast（参见 [design-tokens](./design-tokens.md) 第 6.4 节）

## 9. 空状态与加载态

### 9.1 今日计划为空（新用户首次使用）

```
┌─────────────────────────────────────┐
│  今日计划                            │
│                                     │
│        📋 还没有任何计划             │
│     点击下方 + 按钮创建第一个任务      │
│                                     │
└─────────────────────────────────────┘
```

- 混合列表区域显示空状态插画（极简线条） + 引导文案
- 概览卡片数字全部显示为 `0`
- 宜忌卡片正常展示（不依赖用户数据）

### 9.2 数据加载中

- 列表区域显示 2-3 个骨架屏卡片（灰色圆角矩形脉冲动画）
- 概览卡片数字显示 `—`（短横线）
- 加载完成后渐入替换骨架屏

### 9.3 数据加载失败

- Toast 提示「数据加载失败，请下拉重试」
- 保持上一次成功加载的数据（如果有）
- 新用户首次加载失败：显示错误页 + 重试按钮

### 9.4 添加计划表单提交失败

- 按钮显示「提交中…」并禁用
- 失败后按钮恢复，Toast 提示「创建失败，请重试」
