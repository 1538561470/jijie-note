# Design Tokens — 视觉设计规范

> **能力标识:** `design-tokens`  
> **优先级:** P0（全局依赖）  
> **Phase:** Phase 1（随 MVP 落地）  
> **适用范围:** 所有页面及组件  
> **状态:** 草稿
> **根设计:** [design.md](../design.md)（Commands/目录/代码风格/测试/边界）

---

## 1. 设计语言

| 维度 | 选择 |
|------|------|
| 风格 | 克制东方极简，宣纸白为底，黛蓝为骨，朱砂点睛 |
| 交互 | 扁平化、留白呼吸、内阴影替代分割线、印章式完成标记 |
| 平台 | 微信小程序（WXML + WXSS + JavaScript/TypeScript + 微信云开发） |

### 1.1 负面提示词

| ❌ 避免 | ✅ 采用 |
|---------|--------|
| 紫色渐变 + 白色背景 | 宣纸暖白 + 黛蓝 + 朱砂红 |
| 粗重阴影 / 拟物化 | 极轻内阴影，呼吸感 |
| 复杂纹理背景 | 纯色 + 极淡质感 |
| 欧美卡通图标 | 极简几何描边图标 |
| 信息密度过高 | 每屏适量卡片，大量留白 |
| 霓虹灯 / 荧光色 | 低饱和度传统色 |
| 西式 RPG 叫法（战士/法师） | 中国式称号（潜龙勿用/见龙在田） |
| 卡通宠物（小猫小狗） | 水墨锦鲤，有文化底蕴 |
| 依赖网络的玄学算法 | 本地查表，离线可用 |

## 2. 色板

| Token | 色值 | 用途 |
|-------|------|------|
| `--paper-white` | `#F7F4ED` | 页面主背景，宣纸暖白 |
| `--card-bg` | `#FCFAF6` | 卡片背景 |
| `--ink-black` | `#2C2C2C` | 主要文字 |
| `--ink-secondary` | `#6B6560` | 次要文字 |
| `--ink-tertiary` | `#9C9690` | 辅助文字 |
| `--indigo-deep` | `#4A5568` | 主色调（导航选中态、强调） |
| `--cinnabar` | `#C04040` | 朱砂红点睛（高优先级、印章） |
| `--seal-red` | `#B84040` | 印章色 |
| `--input-bg` | `#F2EFE9` | 输入区域背景 |
| `--gold` | `#C9943A` | 金色（锦鲤 Lv.9 特效） |

### 2.1 色彩使用规则

- 页面背景必须使用 `--paper-white`，禁止使用纯白 `#FFFFFF`
- 卡片背景使用 `--card-bg`，与页面背景形成微弱对比
- 主要文字使用 `--ink-black`，次要文字使用 `--ink-secondary`
- 朱砂红 (`--cinnabar`) 仅用于：高优先级标记、印章动画、打卡标记点
- 分割线效果使用**极轻内阴影**代替，不得使用 `border` 或 `hr` 线框

## 3. 字体层级

| 层级 | 字重 | 字号 | 行高 | 场景 |
|------|------|------|------|------|
| 公历日期 | Weight 600 | 28px | 1.3 | 日期大标题 |
| 弹窗标题 | Weight 700 | 18px | 1.4 | 新建计划弹窗 |
| 用户名 | Weight 600 | 18px | 1.4 | 我的页面 |
| 任务标题 | Weight 500 | 15px | 1.5 | 任务卡片 |
| 菜单项 | Weight 400 | 15px | 1.5 | 设置菜单 |
| 农历/干支 | Weight 400 | 14px | 1.5 | 农历显示 |
| 宜忌标签 | Weight 500 | 12px | 1.4 | 宜忌卡片 |
| 分类标签 | Weight 500 | 10px | 1.3 | 任务分类 |

### 3.1 字体选择

| 场景 | 字体 | 回退 |
|------|------|------|
| 标题 | Noto Serif SC（宋体风） | 系统宋体 |
| 正文 | Noto Sans SC（思源黑体） | PingFang SC |
| 数字/英文 | 同正文 | — |

> 注：小程序内可通过 `@font-face` 内嵌 Noto Sans SC，或直接使用系统 PingFang SC 以减小包体积。

## 4. 间距与圆角

| Token | 值 | 用途 |
|-------|-----|------|
| 页面边距 | 22px | 左右安全边距 |
| 卡片间距 | 10px | 卡片之间的间隙 |
| 卡片内边距 | 16px | 卡片内容与边缘间距 |
| 圆角小 | 8px | 按钮、输入框 |
| 圆角中 | 14px | 任务卡片 |
| 圆角大 | 20px | 个人资料卡片 |

### 4.1 布局规则

- 所有页面左右安全边距固定 22px
- 列表型页面上下间距 16px
- 卡片之间不使用分割线，通过间距 + 内阴影区分
- 内阴影参数：`box-shadow: inset 0 1px 2px rgba(44,44,44,0.04)`

## 6. 动画规范

### 6.1 通用缓动曲线

| 场景 | 曲线 | 时长 |
|------|------|------|
| 表单滑入 | `cubic-bezier(0.34, 1.56, 0.64, 1)` 弹性缓出 | 0.4s |
| 页面切换 | `ease` | 0.3s |
| 印章弹出 | 多段 keyframes（见 6.2） | 0.6s |
| Toast 显示/隐藏 | `ease` | 0.25s |

### 6.2 任务完成动画（印章弹出）

```
阶段 1 (0-150ms): scale(2.5) + rotate(18°) + opacity(0)
阶段 2 (150-250ms): scale(0.95) + opacity(0.9)
阶段 3 (250-350ms): scale(1.05)
阶段 4 (350-600ms): scale(1) + rotate(18°) + opacity(0.85)
```

### 6.3 导航切换动画

- 选中 Tab 的图标 + 标签由 `--ink-tertiary` 渐变为 `--indigo-deep`
- 选中 Tab 顶部出现 `--indigo-deep` 指示条（宽度动画 0.2s）
- 页面内容切换使用 `fade-in`（0.3s ease）

### 6.4 Toast 规范

| 属性 | 值 |
|------|-----|
| 位置 | 页面顶部居中 |
| 背景 | 黑色胶囊（`rgba(44,44,44,0.9)`） |
| 文字色 | 白色 |
| 圆角 | 20px |
| 显示时长 | 1.8s 后自动消失 |

```css
/* 色板 */

--card-bg: #FCFAF6;
--ink-black: #2C2C2C;
--ink-secondary: #6B6560;

--cinnabar: #C04040;
--seal-red: #B84040;

--gold: #C9943A;

/* 间距 */
--page-margin: 22px;
--card-gap: 10px;
--card-padding: 16px;

/* 圆角 */
--radius-sm: 8px;
--radius-md: 14px;
--radius-lg: 20px;

--font-title: 'Noto Serif SC', serif;

/* 阴影 */
--shadow-inner: inset 0 1px 2px rgba(44,44,44,0.04);
```
