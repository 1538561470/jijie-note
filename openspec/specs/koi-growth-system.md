# Koi Growth System — 锦鲤成长系统

> **能力标识:** `koi-growth-system`  
> **优先级:** P0  
> **Phase:** Phase 2（基础系统）/ Phase 5（图鉴+化龙动画）  
> **依赖:** `design-tokens`, `task-management`, `habit-tracking`  
> **状态:** 草稿
> **根设计:** [design.md](../design.md)（Commands/目录/代码风格/测试/边界）

---

## 1. 概述

锦鲤成长系统是「素简」的核心差异化功能。用户通过完成任务和习惯打卡积累经验值，提升锦鲤等级。锦鲤的外观随等级从鱼卵逐步演化为金色锦鲤，最终「鱼跃龙门·化龙」。

---

## 2. 等级体系

### 2.1 等级总览

| 等级 | 锦鲤形态 | 升级条件 | 解锁特效 |
|------|----------|----------|----------|
| Lv.0 | 🥚 鱼卵 | 注册即获得 | — |
| Lv.1 | 透明小鱼苗 | 累计完成 10 个任务 | — |
| Lv.2 | 浅墨鱼苗，可见眼睛 | 累计完成 20 个任务 | — |
| Lv.3 | 淡墨小鱼，尾鳍可见 | 累计完成 30 个任务 | 静止时有微弱游动 |
| Lv.4 | 灰色半大鱼 | 50 任务 + 1 条≥7天习惯链 | 游动动画加速 |
| Lv.5 | 深灰成鱼，鳞片纹理出现 | 70 任务 + 2 条≥7天习惯链 | 点击锦鲤会靠近 |
| Lv.6 | 墨色成鱼，背鳍成型 | 100 任务 + 1 条≥21天习惯链 | 每日首次打开锦鲤跃水 |
| Lv.7 | 🐟 朱砂色锦鲤初现 | 150 任务 + 2 条≥21天习惯链 | 页面背景淡淡朱砂光晕 |
| Lv.8 | 红白锦鲤，鳞片分明 | 200 任务 + 3 条≥21天习惯链 | 游动带水波纹拖尾 |
| Lv.9 | 金色锦鲤，须鳍飘逸 | 500 任务 + 5 条≥21天习惯链 | 全屏水波特效 |
| Lv.10 | 🐉 鱼跃龙门·化龙 | 1000 任务 + **单个习惯**连续打卡 365 天不中断 | 「鱼跃龙门」全屏动画 |

> **关于 Lv.10「365 天连续打卡」的定义：** 指**单个习惯**从某天起连续打卡 365 天不中断（中间断一天即重置）。该条件极其苛刻，是满级的终极挑战。
> **关于「习惯链」的定义：** 升级条件中的「N 条≥7天习惯链」指**当前保持** ≥7 天连续打卡的习惯数量。例如某习惯正在连续第 10 天，计 1 条；中断后降至 0。同一习惯可多次达到≥7天，但中断后需重新累计才再次计为 1 条。

### 2.2 等级称号（段位）

| 段位 | 称号 | 等级范围 |
|------|------|----------|
| 初学 | 潜龙勿用 | Lv.0-2 |
| 小成 | 见龙在田 | Lv.3-4 |
| 有成 | 君子终日乾乾 | Lv.5-6 |
| 大成 | 或跃在渊 | Lv.7-8 |
| 圆满 | 飞龙在天 | Lv.9-10 |

> **段位显示位置：**「我的」页面锦鲤展示区、锦鲤图鉴页。

## 3. 经验值设计

### 3.1 经验值获取

| 行为 | 经验值 | 限制 |
|------|--------|------|
| 完成一个任务 | +10 exp | 每日上限无 |
| 完成一次习惯打卡 | +5 exp | 每日上限无 |
| 连续 7 天打卡（一次性） | +50 exp | 每个习惯独立计算 |
| 连续 21 天打卡（一次性） | +200 exp | 每个习惯独立计算 |
| 连续 100 天打卡（一次性） | +1000 exp | 仅一次 |
| 每日登录 | +2 exp | 每日上限 1 次 |

### 3.2 经验条展示

```
Lv.7 │═══════●═══════│ 68%
     │               │
  当前经验值      升级所需经验值
  680/1000        （各等级所需不同）
```

- 经验条使用 `--indigo-deep` 填充
- 当前进度点使用 `●`（`--cinnabar` 朱砂红）
- 百分比显示在当前等级中的进度

### 3.3 等级升级所需经验（建议值）

| 等级 | 累计经验值 | 本级所需 |
|------|-----------|---------|
| Lv.0 | 0 | 0 |

| Lv.2 | 250 | 150 |
| Lv.3 | 450 | 200 |
| Lv.4 | 750 | 300 |
| Lv.5 | 1100 | 350 |

## 4. 锦鲤视觉实现

### 4.1 实现技术

| 技术 | 用途 | 说明 |
|------|------|------|
| SVG | 锦鲤绘制 | 使用内联 SVG 绘制水墨风格锦鲤，不使用位图 |
| CSS @keyframes | 游动动画 | `transform` 实现缓慢浮动 + 尾鳍摆动 |
| CSS animation | 特效动画 | 跃水、波纹、光晕等 |
| 小程序动画 API | 交互反馈 | 点击靠近、升级过渡 |

### 4.2 锦鲤外观随等级变化

| 维度 | Lv.0-2 | Lv.3-4 | Lv.5-6 | Lv.7-8 | Lv.9-10 |
|------|--------|--------|--------|--------|---------|
| 颜色 | 透明→浅墨 | 淡墨→灰 | 深灰→墨色 | 朱砂红→红白 | 金色 |
| 鳞片 | 无 | 隐约 | 清晰 | 分明 | 清晰+光泽 |
| 尾鳍 | 无 | 可见 | 成型 | 飘逸 | 长须飘逸 |
| 眼睛 | 无→可见 | 可见 | 有神 | 有神 | 灵性 |

### 4.3 SVG 锦鲤结构（伪代码）

```svg
<svg>
  <!-- 身体：根据等级改变 fill 颜色 -->
  <path class="body" d="..." />
  <!-- 尾鳍：根据等级改变大小和透明度 -->
  <path class="tail" d="..." />
  <!-- 鳍：高等级时添加 -->
  <path class="fin" d="..." />
  <!-- 眼睛：Lv.2+ 添加 -->
  <circle class="eye" />
  <!-- 须：Lv.9+ 添加 -->
  <path class="barbel" d="..." />
</svg>
```

### 4.4 关键动画

#### 游动动画（Lv.3+）

```css
@keyframes swim {
  0%, 100% { transform: translateY(0) rotate(0deg); }
  25%      { transform: translateY(-3px) rotate(1deg); }
  50%      { transform: translateY(0) rotate(0deg); }
  75%      { transform: translateY(3px) rotate(-1deg); }
}
```

| 等级 | 动画速度 | 幅度 |
|------|----------|------|
| Lv.3-4 | 6s 循环 | ±2px |
| Lv.5-6 | 4s 循环 | ±3px |
| Lv.7-8 | 3s 循环 | ±4px |
| Lv.9-10 | 2.5s 循环 | ±5px |

#### 跃水动画（Lv.6+ 每日首次打开）

1. 锦鲤从底部跃出（`translateY(60px) → 0`）
2. 身体弯曲（`rotate(-15deg) → 0`）
3. 水花粒子（CSS 伪元素）
4. 平静后恢复游动

#### 化龙动画（Lv.10 特典）

全屏水墨风格「鱼跃龙门」动画：
1. 锦鲤放大至屏幕中央
2. 背景出现水墨龙门（SVG 绘制）
3. 锦鲤转化为龙形（SVG morph）
4. 全屏水波扩散
5. 文字浮现「鱼跃龙门·化龙」

## 5. 锦鲤图鉴（Phase 5）

### 5.1 图鉴展示

位于「我的」页面菜单中，展示所有等级的锦鲤预览。

| 等级 | 显示 | 解锁状态 |
|------|------|----------|
| 当前等级 | 完整展示 + 动画 | 已解锁 |
| 已通过等级 | 静态图 + 等级标记 | 已解锁 |
| 未达到等级 | 剪影 + 🔒 锁 | 未解锁 |

### 5.2 图鉴交互

- 点击已解锁等级 → 大图预览 + 等级说明
- 点击未解锁等级 → 「还需 XX 任务 / XX 习惯链解锁」
- 滑动浏览所有等级

### 5.3 空状态

- **新用户（Lv.0）首次进入图鉴**：仅 Lv.0 鱼卵可查看完整形态，其余等级全部显示为 🔒 剪影
- **图鉴无加载延迟**（数据为本地常量）
- **提示文案**：`完成第一个任务来解锁你的锦鲤吧！`

## 6. 加载与错误状态

### 6.1 加载中

- 锦鲤数据随用户数据一起加载，无独立加载态
- 若用户数据尚未就绪：锦鲤区域显示 `--ink-tertiary` 灰色占位

### 6.2 升级动画触发

- 完成任务/打卡后经验值到达升级阈值 → 自动弹出升级提示
- 动画过程中用户可点击跳过
- 如果多个行为同时触发多次升级（如领取连续奖励连续升级），按等级顺序依次播放动画

### 6.3 数据异常

- 锦鲤数据（等级/经验值）与云端不一致时，以云端为准
- 本地经验值计算错误可触发云端同步校正

## 7. 数据模型

```javascript
// 用户锦鲤数据（User 模型的一部分）
{
  openid: String,
  koiLevel: Number,           // 当前等级 0-10
  koiExp: Number,             // 当前经验值
  totalTasksCompleted: Number, // 累计完成任务数
  longestStreak: Number,      // 最长连续打卡天数
  streakChain7: Number,       // ≥7天习惯链数量
  streakChain21: Number,      // ≥21天习惯链数量
  lastLoginDate: String,      // 上次登录日期（用于登录奖励）
  hasClaimedStreakReward: {   // 是否已领取各连续天数奖励
    "7": Boolean,
    "21": Boolean,
    "100": Boolean
  }
}
```

| # | 验收项 | 预期结果 |
|---|--------|---------|
| 1 | 注册后 Lv.0 | 新用户显示鱼卵 |

| 3 | 习惯打卡 +5 exp | 每次打卡经验值增加 |

| 5 | 锦鲤外观随等级变化 | Lv.1 小鱼苗 → Lv.7 朱砂色 → Lv.10 化龙 |
| 6 | 游动动画流畅 | 无卡顿、闪烁 |
| 7 | 图鉴显示正确 | 已解锁可预览，未解锁显示锁 |
| 8 | 登录奖励每日一次 | 跨天登录才 +2 exp |
