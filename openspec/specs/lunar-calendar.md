# Lunar Calendar — 农历日历

> **能力标识:** `lunar-calendar`  
> **优先级:** P0  
> **Phase:** Phase 1（MVP 基础显示）/ Phase 4（打卡月历）  
> **依赖:** `design-tokens`, `habit-tracking`
> **干支数据来源:** `yiji-recommendation`（复用其天干地支查表）  
> **状态:** 草稿
> **根设计:** [design.md](../design.md)（Commands/目录/代码风格/测试/边界）

---

## 1. 概述

农历日历系统提供两个核心能力：
1. **首页日期显示**：实时显示公历 + 农历 + 干支 + 五行（Phase 1）
2. **打卡月历**：清单·打卡页中的月度日历视图，展示每日打卡状态（Phase 4）

---

## 2. 数据模型

### 2.1 农历查表

使用预置农历数据表（JSON），包含未来 5-10 年的农历转换数据。

```javascript
// lunar-data.json 结构
{
  "2025": {
    "months": {
      "1": { "leap": false, "days": 29 },
      "2": { "leap": false, "days": 30 },
      // ...
    },
    "leapMonth": 6        // 0 = 无闰月
  }
}
```

### 2.2 农历日期计算

```javascript
输入: 公历 2025-10-15
输出: {
  lunarYear: "乙巳年",
  lunarMonth: "八月",
  lunarDay: "廿三",
  ganzhi: "庚申日",       // 来自 yiji-recommendation 的天干地支查表
  wuxing: "金旺",         // 来自 yiji-recommendation 的五行映射
  term: null              // 节气（如有）
}
```

> 干支和五行数据直接从 `yiji-recommendation` 的查表结果获取，不重复计算。详见 [yiji-recommendation](./yiji-recommendation.md) 第 3-4 节。

## 3. 首页日期显示（Phase 1）

### 3.1 显示位置

首页问候区下方，宜忌卡片上方。

### 3.2 显示格式

首页显示的日期格式为：**公历 + 农历 + 干支 + 五行**

```
十月十五 · 庚申日 · 金旺
```

> 「十月十五」为公历 10 月 15 日的汉字数字写法；干支和五行由 `yiji-recommendation` 提供。

| 元素 | 说明 | 示例 |
|------|------|------|
| 公历月日 | 格式：M月d日 | 十月十五（注意：是公历月份，用汉字数字） |
| 干支 | 日柱的干支 | 庚申日 |
| 五行 | 日干五行属性 | 金旺 |

### 3.3 样式

| 属性 | 值 |
|------|-----|
| 字体 | `--font-body`，Weight 400 |
| 字号 | 14px（参见 [design-tokens](./design-tokens.md) 第 3 节「农历/干支」层级） |
| 颜色 | `--ink-secondary` |

## 4. 打卡月历（Phase 4）

### 4.1 月历布局

打卡月历展示的是**农历月份**的每日打卡情况。例如公历 10 月可能对应农历八月或九月，页面标题为「八月 2025」。

```
┌──────────────────────────────┐
│     八月 2025                │  ← 农历月 + 公历年
│  一  二  三  四  五  六  日   │
│      1   2   3   4   5   6   │
│            🔴  🔴            │  ← 已打卡日
│  7   8   9  10  11  12  13  │
│  🔴  🔴      🔴  🔴  🔴    │
│  ...                         │
├──────────────────────────────┤
│  连续打卡：🔥 7天「一周有成」   │
└──────────────────────────────┘
```

### 4.2 元素说明

| 元素 | 说明 |
|------|------|
| 标题栏 | 「八月 2025」（**农历月**中文名 + 公历年份） |
| 星期栏 | 一 二 三 四 五 六 日（中文缩写） |
| 日期格 | 公历日期数字（日期格内标注的是公历日数） |
| 打卡标记 | 已打卡日显示朱砂红圆点 `🔴`（`--cinnabar`） |
| 今日 | 今日日期用特殊高亮（`--indigo-deep` 边框） |
| 底部栏 | 最长连续天数 + 中文称号 |

### 4.3 打卡标记规则

| 状态 | 显示 |
|------|------|
| 当日有打卡记录且达到 target | 🔴 朱砂红圆点 |
| 当日有打卡但未达 target | 🔴 半透明朱砂红圆点 |
| 当日无打卡记录 | 无标记 |
| 未来日期 | 灰色文字 `--ink-tertiary` |
| 今日 | `--indigo-deep` 边框高亮 |

### 4.4 月份切换

- 左右滑动切换月份
- 点击月份标题区域可弹出月份选择器
- 动画：水平滑动切换，0.3s ease

### 4.5 底部连续天数

```
连续打卡：🔥 7天「一周有成」
```

- 显示**所有习惯中的最长连续天数**
- 同步更新中文称号（参见 [habit-tracking](./habit-tracking.md) 第 4.2 节）

## 5. 空状态与加载态

### 5.1 无打卡记录

- **新用户首次打开月历**（第一周）：月历显示空月份，无任何红色标记
- **当月无打卡**：月历正常显示，只是所有日期格内无 🔴 标记
- **底部连续天数**：显示 `🔥 尚未开始打卡`

### 5.2 农历数据加载失败

- 本地 JSON 数据缺失或损坏：回退为仅显示公历日期，隐藏农历/干支信息
- 文案提示：`农历数据加载中…` → 若失败不阻塞页面渲染

### 5.3 打卡数据加载中

- 月历区域显示骨架屏（灰色方格占位）
- 加载完成后渐入显示

## 6. 农历数据源

### 5.1 数据生成

推荐使用开源农历数据（如 `lunar-calendar-js` 或类似库）预生成 JSON 数据文件。

| 维度 | 规格 |
|------|------|
| 覆盖年限 | 当前年份 ±5 年（共 10 年） |
| 数据量 | 约 50-100KB |
| 更新策略 | 随小程序版本更新 |
| 离线要求 | 完全离线可用 |

### 5.2 数据结构

```javascript
// 核心转换函数接口
function solarToLunar(year, month, day) {
  // 返回:
  return {
    lunarYear: number,       // 农历年
    lunarMonth: number,      // 农历月（1-12）
    lunarDay: number,        // 农历日（1-29/30）
    isLeap: boolean,         // 是否闰月
    yearGanZhi: string,      // 年干支
    monthGanZhi: string,     // 月干支
    dayGanZhi: string,       // 日干支
    zodiac: string,          // 生肖
    term: string | null      // 节气
  };
}
```
