## 一、产品概述

### 1.1 产品定位
一款**融合中国传统文化的个人计划管理与微习惯养成**微信小程序。以「素简」为核心理念，将计划管理、微习惯打卡、八卦五行宜忌推荐、锦鲤成长系统四位一体，打造市面上独树一帜的中国风自律工具。

### 1.2 核心差异化
市面上的计划管理工具（滴答清单、Todoist、朝夕）和习惯打卡工具（小日常、Streaks）各自为战。**「素简」将它们融合**，并加入中国独有的八卦五行·今日宜忌与锦鲤成长系统，形成功能上的差异化壁垒。

### 1.3 目标用户
- 25-40岁中国白领/知识工作者
- 注重生活品质、有中国文化认同感
- 有任务管理和习惯养成双重需求
- 对西方UI审美疲劳，追求有文化底蕴的设计

### 1.4 设计语言

| 维度 | 选择 |
|------|------|
| 风格 | 克制东方极简，宣纸白为底，黛蓝为骨，朱砂点睛 |
| 主色调 | 宣纸白 `#F7F4ED`、黛蓝 `#4A5568`、朱砂红 `#C04040`、墨黑 `#2C2C2C` |
| 字体 | 标题: Noto Serif SC（宋体风）；正文: Noto Sans SC（思源黑体） |
| 交互 | 扁平化、留白呼吸、内阴影替代分割线、印章式完成标记 |
| 平台 | 微信小程序（WXML + WXSS + JavaScript/TypeScript + 微信云开发） |

#### 3.1.1 今日宜忌卡片

**数据来源：** 根据公历日期计算天干地支的查表算法，无需联网。

| 元素 | 内容 | 示例 |
|------|------|------|
| 干支 | 年柱+月柱+日柱 | 庚申日 |
| 五行 | 日干对应的五行属性 | 金旺 |
| 宜 | 根据五行推荐的当日事项（关联用户已设习惯） | 宜读书、宜静坐、宜复盘 |
| 忌 | 当日应避免的行为提示 | 忌冲动决策 |

**交互：** 点击「宜」项目直接跳转对应习惯的打卡页。

#### 3.1.2 概览卡片

| 卡片 | 数据 | 说明 |
|------|------|------|
| 全部任务 | 总任务数 | 含已完成 |
| 待完成 | 未完成任务数 | 朱砂红圆点装饰 |
| 今日习惯 | 已打卡/总习惯数 | 新增卡片，与任务卡片区分 |

#### 3.1.3 任务·习惯混合列表

任务和习惯在同一个信息流中平级展示，用不同的前置图标区分：
- 任务：圆形勾选框 `○`
- 习惯：复选框 `☑` + 连续天数🔥

**任务交互：** 点击任务任意位置切换完成状态，完成后任务置灰（opacity: 0.6），标题显示朱砂色删除线，右侧出现「完」字印章动画。

**习惯交互：** 点击习惯切换打卡状态，打卡后在月度日历上盖朱砂印。连续天数用中文表达：7天「一周有成」、21天「三周之功」、100天「百日筑基」。

#### 3.1.4 添加计划/习惯

底部抽屉表单，包含：
- 计划名称（必填）
- 备注（选填）
- 优先级选择：重要 / 普通 / 不急
- 分类选择：生活 / 工作 / 学习 / 健康
- 类型切换：任务 / 习惯（选习惯时额外展示频率设置）

习惯频率设置：
- 每天
- 工作日（周一至周五）
- 自定义（勾选具体星期几）

## 四、锦鲤成长系统 详细设计

### 4.1 等级体系

| 等级 | 锦鲤形态 | 升级条件 | 解锁特效 |
|------|----------|----------|----------|
| Lv.0 | 🥚 鱼卵 | 注册即获得 | — |
| Lv.1 | 透明小鱼苗 | 累计完成 10 个任务 | — |
| Lv.2 | 浅墨鱼苗，可见眼睛 | 累计完成 20 个任务 | — |
| Lv.3 | 淡墨小鱼，尾鳍可见 | 累计完成 30 个任务 | 静止时有微弱游动 |
| Lv.4 | 灰色半大鱼 | 50 任务 + 1 条≥7天习惯链 | 游动动画加速 |
| Lv.5 | 深灰成鱼，鳞片纹理出现 | 70 任务 + 2 条≥7天习惯链 | 点击锦鲤会靠近 |
| Lv.6 | 墨色成鱼，背鳍成型 | 100 任务 + 1 条≥21天习惯链 | 每日首次打开锦鲤跃水 |
| Lv.7 | 🐟 朱砂色锦鲤初现 | 150 任务 + 2 条≥21天习惯链 | 页面背景淡淡朱砂光晕 |
| Lv.8 | 红白锦鲤，鳞片分明 | 200 任务 + 3 条≥21天习惯链 | 游动带水波纹拖尾 |
| Lv.9 | 金色锦鲤，须鳍飘逸 | 500 任务 + 5 条≥21天习惯链 | 全屏水波特效 |
| Lv.10 | 🐉 鱼跃龙门·化龙 | 1000 任务 + 365 天连续打卡 | 「鱼跃龙门」全屏动画 |

### 4.2 经验值设计

| 行为 | 经验值 | 说明 |
|------|--------|------|
| 完成一个任务 | +10 exp | 每日上限无 |
| 完成一次习惯打卡 | +5 exp | 每日上限无 |
| 连续 7 天打卡 | +50 exp（一次性奖励） | 每个习惯独立计算 |
| 连续 21 天打卡 | +200 exp（一次性奖励） | 每个习惯独立计算 |
| 连续 100 天打卡 | +1000 exp（一次性奖励） | 仅一次 |
| 登录 | +2 exp | 每日上限 1 次 |

### 4.3 锦鲤视觉实现

- 使用 **SVG + CSS 动画** 绘制水墨风格锦鲤，不使用位图图片
- 锦鲤身体随等级变化颜色（透明→淡墨→深灰→朱砂红→金色）
- 游动动画：CSS `transform` 实现缓慢浮动 + 尾鳍摆动
- 跃水动画：突破大等级时触发，锦鲤从水中跃出再落下
- 化龙动画：Lv.10 触发全屏「鱼跃龙门」水墨风格 CS 动画

### 4.4 等级称号（中国式表达）

| 段位 | 称号 | 条件 |
|------|------|------|
| 初学 | 潜龙勿用 | Lv.0-2 |

## 五、八卦五行·今日宜忌 算法说明

### 5.1 天干地支计算

基于公历日期查表法计算年柱、月柱、日柱，无需网络请求。

```
输入: 2025年10月15日
计算:
  年柱 → 乙巳年
  月柱 → 丙戌月
  日柱 → 庚申日
输出: 庚申日 · 金旺
```

### 5.2 宜忌推荐规则

| 五行 | 宜 | 忌 | 关联习惯 |
|------|----|----|---------|
| 金旺 | 读书、静坐、复盘 | 冲动决策 | 阅读、冥想、日记 |
| 木旺 | 运动、写作、规划 | 过度劳累 | 跑步、写作、计划 |
| 水旺 | 社交、学习、创作 | 熬夜 | 社交、学习、创作 |
| 火旺 | 执行、整理、沟通 | 急躁行事 | 行动、整理、沟通 |
| 土旺 | 反思、修养、规划 | 拖延 | 冥想、日记、规划 |

### 5.3 中国化时间表达

| 连续天数 | 中文称号 | 解锁条件 |
|----------|----------|----------|
| 7 天 | 一周有成 | 首次连续 7 天打卡 |

## 六、微习惯打卡 详细设计

### 6.1 习惯数据结构

```javascript
{
  id: String,              // 唯一标识
  name: String,            // 习惯名称（如「喝水」）
  target: Number,          // 每日目标次数（如 8 杯）
  unit: String,            // 单位（如「杯」「分钟」「页」）
  frequency: {             // 频率设置
    type: 'daily' | 'weekday' | 'custom',
    days: [1,2,3,4,5]     // 当 type='custom' 时，1=周一 7=周日
  },
  category: String,        // 分类（生活/工作/学习/健康）
  createdAt: Date,
  records: [               // 打卡记录
    { date: '2025-10-15', count: 8 }
  ]
}
```

### 6.2 打卡逻辑

- 每日可多次打卡（如喝水 8 杯可分多次记录）
- 达到当日目标即视为当日完成
- 连续天数：从最近一次未完成日开始向前计算
- 连续天数断掉不扣除经验值，仅重置连续计数

## 七、页面交互规范

### 7.1 导航

底部三页导航，图标使用极简几何描边 SVG（stroke-width: 1.5px，stroke-linecap: round）：

| Tab | 图标 | 页面 |
|-----|------|------|
| 首页 | 房屋轮廓 | 今日概览 |
| 清单·打卡 | 三线菜单 + 日历 | 任务清单 + 打卡月历 |
| 我的 | 人物轮廓 | 个人中心 + 锦鲤 |

选中态：图标 + 标签由灰色变为黛蓝 `#4A5568`，顶部出现黛蓝指示条动画。

### 7.2 任务完成动画

1. 点击任务卡片
2. 卡片微缩（scale: 0.985）
3. 勾选框由空心圆变为朱砂红实心 + 白色勾
4. 右侧「完」字印章弹出动画：
   - 起始：scale(2.5) + rotate(18°) + opacity(0)
   - 中间：scale(0.95) + opacity(0.9)
   - 回弹：scale(1.05)
   - 稳定：scale(1) + rotate(18°) + opacity(0.85)
5. 卡片整体透明度降至 0.6
6. 标题显示朱砂色删除线

### 7.3 添加计划表单

底部滑入抽屉（0.4s cubic-bezier 弹性缓出），遮罩可点击关闭。
表单项使用色块 `#F2EFE9` 区分区域，不使用分割线。

### 7.4 Toast 反馈

操作完成后顶部黑色胶囊提示，1.8 秒后自动消失。
